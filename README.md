# 🚀 EdTech — Web Solutions Studio

A high-converting, modern web solutions studio landing page engineered for performance, conversion, and visual craft. Built with vanilla web standards, featuring an interactive mini-games engine, lead routing, and search engine optimization.

---

## ✨ Features

- **🎨 Modern Dark-Mode Aesthetics**: Tailored design tokens, glassmorphism cards, fluid typography, and micro-interactions.
- **🎮 In-Browser Mini-Games Engine**: Four fully interactive games built in pure JavaScript with zero dependencies:
  - **Snake Arcade**: Classic snake with arrow keys, WASD, and virtual mobile D-Pad.
  - **Memory Match**: Card matching with score tracking.
  - **Typing Speed Test**: 60-second WPM and accuracy test.
  - **2048 Puzzle**: Number puzzle with keyboard arrows and mobile swipe/D-Pad.
- **📬 Live Lead Capture**: Contact form with validation, animated state transitions, global toast notifications, EmailJS forwarding, and an automatic offline fallback.
- **⚡ Performance & CLS Elimination**: Explicit image dimensions, asynchronous decoding, and Google Font preconnect hints for sub-second rendering.
- **🌐 SEO & Social Sharing**: Complete OpenGraph, Twitter Card meta tags, `robots.txt`, and `sitemap.xml`.
- **♿ WCAG 2.1 AA Accessibility**: Hidden keyboard "Skip to main content" link, `aria-required` inputs, and `aria-hidden` decorative SVGs.
- **🛡️ Production Hardened**: Vercel configuration (`vercel.json`) with clean URLs and strict security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`).

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom design system & tokens)
- **Scripting**: Modern JavaScript (ES6+)
- **Integration**: EmailJS SDK
- **Hosting / Deployment**: Vercel
